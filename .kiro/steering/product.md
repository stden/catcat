# Product Overview

SleepyCat — кроссплатформенный десктоп-питомец на Electron для Windows и macOS.

## Key Features

- Прозрачное безрамочное окно, всегда поверх других окон
- Анимированный кот, который ходит по экрану, спит, потягивается
- Система состояний: walk, sleep, stretch, idle
- Автоматические переходы между состояниями
- Опциональный режим "клик-сквозь"

## Target Users

- Пользователи Windows 10+ и macOS 11+
- Любители десктоп-питомцев и милых анимаций

## Goals

- Создать простого, но живого виртуального питомца
- Обеспечить кроссплатформенность без сложных зависимостей
- Минималистичный код на ванильном JavaScript
